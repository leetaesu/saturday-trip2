# 엄마 칠순여행 · 함께라서 좋은 날 (`saturday-trip2`)

2026.11.22(일)~11.23(월) 1박 2일, 춘천에서 자가용으로 출발해 오색그린야드호텔에 머무르는 가족 여행(엄마·막내이모·형·동생) 전용 모바일 웹 플래너입니다. 큰 글씨, 단순한 안내, 큰 버튼과 따뜻한 가족여행 분위기로 설계했으며 비용과 금액은 화면에 표시하지 않습니다.

## 실행 및 테스트

Node.js 22 환경에서 실행·빌드·테스트할 수 있습니다. (현재 저장소의 `node_modules`는 로컬 환경에 맞춰 연결되어 있습니다.)

```bash
npm run dev        # 개발 서버 실행 (오프라인 Service Worker 미동작)
npm run typecheck  # TypeScript 타입 검사 (tsc --noEmit)
npm test           # 일정 계산·지도 링크·PDF·데이터 빠른 단위 테스트
npm run build      # 타입 검사 + 프로덕션 빌드 (dist/ 및 sw.js 생성)
npm run preview    # 프로덕션 빌드 미리보기 (오프라인 캐시 테스트 가능)
```

## 주요 기능

- **코스별 독립 일정 (A / B / C / D)**:
  - **A코스**: 양양 바다 + 맛집 + 온천 (가장 추천)
  - **B코스**: 한계령 드라이브 + 온천 (통제 상태 입력 시 B코스 데이터를 유지한 채 A코스로 자동 전환)
  - **C코스**: 속초 바다 + 관광 + 온천, 둘째 날 속초관광수산시장
  - **D코스**: 낙산사 + 바다 + 온천 (편안 모드 또는 무릎 통증 체크 시 계단 없는 해변으로 대체)
- **일정 시간 자동 계산 및 편집**:
  - 하루 출발시간 변경 시 뒤 일정 연쇄 재계산
  - 개별 일정의 시작 예정(15:00 이후 체크인 제한, 앞 일정 종료 전 이동 제한), 머무는 시간, 이동 확보 시간, 순서 변경, 추가, 삭제·되돌리기, 선택 관광 건너뛰기·다시 넣기, 완료 체크
  - 연속 관광 3번째 전 자동 휴식 여유 추가, 식사 최소 70분·카페 최소 40분 보장
  - A/B/D 둘째 날에도 **속초시장 넣기** 버튼 제공
- **엄마 편안 모드 및 무릎 보호**:
  - 걷기 5분 이내 목표, 관광 최대 30분 제한, 휴식·카페 최소 시간 확대
  - 계단·무릎 부담이 큰 관광을 해변 휴식으로 대체하며, C코스 영금정처럼 이미 속초해변이 포함된 날에는 중복 왕복 없이 합쳐 생략
- **지도 및 방문 후보 안내**:
  - 위치 권한 없이 사용 가능
  - 네이버지도는 장소 검색 연결, 카카오맵은 OpenStreetMap 확인 좌표가 있을 때만 공식 차량 길찾기(`/link/by/car/`) 또는 위치(`/link/to/`)를 사용하고 미확보 장소는 검색(`/link/search/`)으로 연결
  - `public/places/recommendations.json` 기반 식당·카페 후보(감나무식당, 88생선구이, 김영애할머니순두부 본점, 하조대커피 낙산점, 원파인데이) 및 숙소·온천 안내
- **준비물 · 여행기록 · PDF 앨범**:
  - 카테고리별 준비물 체크
  - 칠순 축하 메시지, 사진 압축 업로드, 장소별 메모 저장·수정·삭제
  - 일정·사진·메시지가 담긴 A4 PDF 앨범(`엄마-칠순여행-앨범.pdf`) 생성 및 다운로드
- **오프라인 지원**:
  - `npm run build` 시 `vite.config.ts`가 `sw.js`를 생성해 앱 정적 파일·가족 그림·참고 사진을 캐시합니다.

## 데이터 저장 방식

- **서버 업로드 및 기기 간 동기화 없음**: 모든 기록은 현재 사용 중인 기기의 브라우저에만 저장됩니다.
- **`localStorage` (`mom70-trip-v2`)**: 선택한 코스, 편안 모드·무릎·도로 설정, 날짜별 출발시간, A/B/C/D 코스별 편집 일정, 준비물 체크, 칠순 축하 메시지
- **`IndexedDB` (`mom70-memories`)**: 최대 1800px JPEG로 압축한 가족사진(`Blob`)과 장소·날짜·메모
- **`sessionStorage` (`mom70-intro`)**: 첫 화면 인트로 모달 확인 여부

브라우저 저장 공간이 부족하거나 시크릿 모드 등으로 저장이 제한된 경우 화면에 안내 메시지를 표시합니다. 브라우저 데이터를 삭제하면 기록이 사라지므로 PDF 앨범으로 백업하는 것을 권장합니다.

## 주요 파일

- `src/App.tsx`: 홈/일정/지도/준비물/여행기록 UI, 모달, 사진·메모 관리
- `src/trip.ts`: A/B/C/D 기본 일정, 장소·주차 정보, 식당·카페 후보, 준비물, 출처
- `src/engine.ts`: 시간 계산, 편안 모드·무릎 대체, 중복 왕복 방지, 지도 링크, 저장 데이터 검증·복원
- `src/storage.ts`: `localStorage` 상태 읽기, `IndexedDB` 사진·메모 CRUD, 사진 압축
- `src/pdf.ts`: 캔버스 기반 한글·사진 렌더링 및 JPEG-backed A4 PDF 생성
- `src/index.css`: 모바일·데스크톱 반응형 스타일
- `vite.config.ts`: 빌드 시 오프라인 Service Worker(`sw.js`) 생성
- `.github/workflows/deploy.yml`: `main` 브랜치 푸시 시 GitHub Pages 자동 빌드·배포
- `public/places/credits.json`, `public/places/recommendations.json`: 참고 사진 저작권·출처 및 식당·카페 후보 원본 데이터

## 제약 및 주의사항

- **실시간 정보 미연동**: 지도 API, 실시간 교통, 도로 통제, 영업시간 자동 조회를 연동하지 않았습니다. 화면의 이동 확보 시간은 계획용 여유이며 실제 차량 소요시간·거리는 지도 앱에서 확인해야 합니다.
- **좌표 기준점 안내**: 지도 좌표 출처는 **OpenStreetMap**입니다. 춘천 출발·귀가 좌표(`37.8813828, 127.7302041`)는 실제 집 주소가 아닌 **춘천시청 부근 기준점**이며, 다른 장소 좌표도 주차장 입구가 아닌 대표 위치입니다.
- **방문 전 확인 필요**: 식당·카페의 영업·휴무·주차·입식 좌석·무단차 입구와 오색그린야드호텔 온천의 복지 예약 포함 여부 및 숙박객 적용 조건은 방문 전 전화로 확인해야 합니다.
- **사진·그림 구분**: `public/family.png`는 인트로에, `public/family-banner.png`는 홈 배너에 사용합니다. `한계령` 사진(`hangyeryeong.jpg`)은 2008년 여름 참고 사진으로 현재 노면·결빙 상태가 아니며, 양양전통시장·숙소·식당·카페는 실사진 대신 안내 그림으로 표시합니다.
- **개발 서버 오프라인 미동작**: Service Worker 오프라인 캐시는 `npm run build` 후 `npm run preview` 또는 정적 호스팅 환경에서만 동작합니다.

## GitHub Pages 배포

1. GitHub 저장소의 **Settings → Pages → Build and deployment → Source**를 **GitHub Actions**로 설정합니다.
2. `main` 브랜치에 푸시하면 `.github/workflows/deploy.yml`이 테스트·빌드 후 `dist/`를 배포합니다. (`base: './'` 설정을 사용하므로 `/saturday-trip2/` 경로에서도 그대로 동작합니다.)
